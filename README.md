# Telecom Customer Churn Analysis

Exploratory data analysis of 7,043 telecom customers to find the factors linked to churn and suggest ways to improve retention.

## Files
- `Customer Churn.csv` – dataset
- `TCA.ipynb` – data cleaning, EDA, and visualizations
- `Telecom Customer Churn Analysis.pdf` – full report with findings and recommendations

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn

## Key Findings
- 26.54% of customers churned (about 1 in 4)
- Month-to-month contracts and short tenure show the highest churn
- Fiber optic users churn more than DSL users
- Customers without Online Security or Tech Support churn more
- Electronic check users account for the most churn cases

*This is exploratory analysis. The findings show associations, not proof of causation.*
